# Analisis Karakteristik Platform

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Arsitektur** | Client-Server | Berdiri sendiri (Standalone) / Client-Server | Berdiri sendiri / Client-Server terdistribusi |
| **Bahasa Utama** | HTML, CSS, JavaScript | Java, C#, C++, Python | Kotlin/Java (Android), Swift (iOS), Dart (Flutter) |
| **Distribusi** | Diakses melalui URL menggunakan Web Browser | File Installer (.exe, .dmg) via website | Diunduh melalui toko aplikasi (Play Store, App Store) |
| **Keunggulan** | Tidak perlu instalasi, akses lintas OS. | Performa tinggi, bisa berjalan offline penuh. | Portabilitas tinggi, akses langsung ke sensor (GPS). |
| **Keterbatasan** | Sangat bergantung pada koneksi internet. | Harus diinstal terlebih dahulu. | Ukuran layar dan baterai terbatas. |
| **Contoh Aplikasi** | Google Docs, Tokopedia (web), GitHub | IntelliJ IDEA, VS Code, Microsoft Word | WhatsApp, Instagram, Gojek |
