# Analisis Karakteristik Platform

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Arsitektur** | Client-Server | Berdiri sendiri (Standalone) / Client-Server | Berdiri sendiri / Client-Server terdistribusi |
| **Bahasa Utama** | HTML, CSS, JavaScript | Java, C#, C++, Python | Kotlin/Java (Android), Swift (iOS), Dart (Flutter) |
| **Distribusi** | Diakses melalui URL menggunakan Web Browser | File Installer (.exe, .dmg, .deb) via website atau App Store | Diunduh melalui toko aplikasi (Google Play Store, Apple App Store) |
| **Keunggulan** | Tidak perlu instalasi, akses lintas OS (Windows, macOS, Linux) asalkan ada browser. | Performa tinggi, bisa berjalan offline penuh, dan memiliki akses leluasa ke perangkat keras (hardware) komputer. | Portabilitas tinggi, bisa diakses di mana saja, serta punya akses langsung ke sensor bawaan (GPS, Kamera, Gyroscope). |
| **Keterbatasan** | Sangat bergantung pada koneksi internet dan akses ke hardware / sistem file lokal sangat dibatasi. | Harus diinstal terlebih dahulu, memakan ruang penyimpanan lokal, dan pembaruan aplikasi seringkali manual. | Ukuran layar terbatas, kapasitas baterai terbatas, serta spesifikasi memori/prosesor tidak sebesar desktop. |
| **Contoh Aplikasi** | Google Docs, Netflix (versi web), Sistem Manajemen Inventaris Berbasis Web | Visual Studio Code, Microsoft Office, Adobe Photoshop | WhatsApp, Instagram, Gojek |
